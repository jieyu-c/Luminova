# PRD：Luminova 画布前端交互设计（四媒体节点）

> 状态：交互设计稿 V2.2 · 仅设计，不实施  
> 原则：**四种媒体节点为唯一一等公民；业务角色是扩展，不是新节点类型**  
> 节点形态：**三层分离** — 顶部悬空工具栏 · 中心媒体展示框 · 底部悬浮模型操作框  
> 显隐：**常驻只显示中心媒体框；点击选中后才弹出顶栏与底栏**  
> 视觉：**与现有** `.canvas-page` **暗色画布一致**（`#0c1018` 底、`#141a24` 节点面、蓝强调 `#3b82f6`、蓝渐变主按钮、点阵网格）  
> 样式参考截图：[canvas-style-reference.png](assets/canvas-style-reference.png)  
> 相关： [统一生成平台架构](prd-generation-platform.md)

常驻 vs 选中常驻态画布

## 1. 设计目标

用户打开画布后，只面对 **文本 / 图片 / 视频 / 音频** 四种节点，用连线组合它们完成：

1. 写提示或对白（文本）
2. 上传或生成参考图（图片）
3. 生成镜头片段（视频）
4. 可选配乐/旁白（音频）
5. 排序并导出成片

不做通用工作流设计器；不做「角色节点 / 场景节点 / 镜头节点」等业务专用类型——这些只是四种媒体节点上的 **用途标签（扩展）**。

## 2. 核心原则


| 原则     | 含义                                                      |
| ------ | ------------------------------------------------------- |
| 四媒体为本  | 工具栏只有文本、图片、视频、音频                                        |
| 扩展非新类型 | 角色 / 场景 / 风格 / 对白 / 镜头 等 = 媒体节点 + `role` / 预设，不是第 5 种节点 |
| 同型可生成  | 图片 / 视频 / 音频节点均可「上传」或「生成」；文本节点可编辑与（可选）改写                |
| 连线即输入  | 边无类型选择器；语义由源媒体 → 目标媒体自动推断                               |
| 常驻极简   | **未选中只渲染中心媒体框**；顶栏/底栏点击后才出现                             |
| 选项极简   | 默认只暴露创作必需字段；高级项折叠                                       |
| 完成成片   | 时间线聚合视频（+ 音频）轨道后导出                                      |




## 3. 四种主节点

四媒体三层结构


| 节点     | 本质    | 中心展示      | 底部操作框默认字段       | 可触发生成  |
| ------ | ----- | --------- | --------------- | ------ |
| **文本** | 字符串内容 | 正文阅读/编辑区  | 模型（可选）、提示/改写    | 可选「改写」 |
| **图片** | 静态画面  | 图片预览      | 模型、提示词、画幅、上传/生成 | **是**  |
| **视频** | 动态片段  | 视频预览 + 播放 | 模型、提示词、时长、画幅、生成 | **是**  |
| **音频** | 声音片段  | 波形 + 播放   | 模型、描述、时长、上传/生成  | 可先只上传  |




### 3.1 节点三层结构（统一外壳）

四种节点共用同一空间结构：**三层分离、各自悬浮**，不是一整块贴死的卡片。

**显隐规则（重要）：**

显隐交互时序


| 状态              | 顶部工具栏 | 中心媒体框     | 底部模型操作框 |
| --------------- | ----- | --------- | ------- |
| **常驻（未选中）**     | 隐藏    | **显示**    | 隐藏      |
| **选中（点击后）**     | 弹出    | 显示（蓝光选中态） | 弹出      |
| **失焦（点空白/选其他）** | 收回    | 显示        | 收回      |


- 画布浏览时节点保持干净，只看媒体内容与连线
- 同一时刻通常只有 **一个** 节点展开顶栏+底栏（跟随当前选中）
- 顶栏/底栏出现可用短过渡（淡入或上下滑入），收回同理
- 连线拖拽时，目标节点可不展开底栏，仅高亮媒体框手柄即可

结构示意（选中态才完整出现 ①③）：

节点三层结构底部模型操作框细节

```text
              ┌─────────────────────────┐
              │ ① 顶部悬空工具栏         │  ← 仅选中时显示
              │  [类型] 复制 下载 ···    │
              └─────────────────────────┘
                         ↕ gap
        ○──── ┌─────────────────────────┐ ────○
              │ ② 中心媒体展示框         │  ← 常驻唯一可见主体
              │                         │
              │   图 / 视频 / 波形 / 文本 │
              │                         │
              └─────────────────────────┘
                         ↕ gap
              ┌─────────────────────────┐
              │ ③ 底部悬浮模型操作框     │  ← 仅选中时显示
              │  模型 · 画幅             │
              │  提示词                  │
              │  时长 ···        [生成]  │
              └─────────────────────────┘
```



#### ① 顶部悬空工具栏（选中后）

- 轻量、图标为主：类型徽标、复制、下载/导出、更多
- 不承载生成参数
- 与媒体框分离，带轻微阴影，呈现「悬空」感



#### ② 中心媒体展示框（常驻）

- 节点视觉中心，面积最大；**未选中时这是节点的全部 UI**
- 按类型渲染：文本正文 / 图片 / 视频（播放钮+时间） / 音频波形
- 左右连接点挂在媒体框上（输入左、输出右）
- 选中态：蓝色描边光晕打在媒体框上



#### ③ 底部悬浮模型操作框（选中后）

- 承载「调用模型」相关信息：模型、prompt、时长、画幅、生成按钮
- 与媒体框分离悬浮；字段保持极简，高级项进「更多设置」
- **右侧大 Inspector 不再作为主参数入口**（可保留为辅助，或后续弱化）

差异只在 **② 的媒体渲染** 与 **③ 的字段集合**，不在交互范式。

### 3.2 底部操作框字段（按媒体）

**文本**

- 正文编辑可在中心框内完成
- 底部（可选）：改写模型、指令、生成/改写

**图片**

- 模型、提示词、画幅（默认 16:9）
- 上传 | 生成
- 用途标签（可选）：参考 / 角色 / 场景 / 风格

**视频**

- 模型、提示词、时长（2/4/6/8s）、画幅
- 生成
- 用途标签（可选）：镜头 / 参考片段

**音频**

- 模型或描述、时长
- 上传 | 生成
- 用途标签（可选）：配乐 / 音效 / 旁白音

> 「用途标签」是扩展，不是新节点。用户可不选；也可根据连线自动建议。



## 4. 扩展映射（旧业务类型如何落地）

扩展映射


| 旧概念 / 后端枚举      | 落在     | 扩展方式                                   |
| --------------- | ------ | -------------------------------------- |
| CHARACTER       | 图片     | `role=character` + 名称                  |
| SCENE           | 图片     | `role=scene`                           |
| STYLE           | 图片     | `role=style`                           |
| ASSET（图）        | 图片     | `role=reference` 或无标签上传                |
| ASSET（视频）       | 视频     | 上传模式                                   |
| ASSET（音频）       | 音频     | 上传模式                                   |
| SHOT            | 视频     | `role=shot`，默认偏生成                      |
| DIALOGUE / TEXT | 文本     | `role=dialogue` / `caption` / `prompt` |
| MUSIC           | 音频     | `role=music`                           |
| EFFECT（视觉）      | 图片或视频  | 后期；首期不单独入口                             |
| SHOT_CONTEXT    | 视频→视频边 | 用连线表达连续性，不另建类型                         |




### 4.1 后端建议

`CanvasNodeType` 收敛为：

```text
TEXT | IMAGE | VIDEO | AUDIO
```

原 10 类枚举降级为 `content.role`（或 `presentation.role`）可选字段。  
迁移期可双写；前端工具栏只认四种。

### 4.2 为何这是对的

- 用户心智是「我在处理什么介质」，不是「我在填业务表单」
- 角色/场景/风格本质都是 **带语义的图片**
- 镜头本质是 **可生成的视频**
- 对白本质是 **文本**；配乐本质是 **音频**
- 扩展用标签实现，避免工具栏与节点组件无限膨胀



## 5. 核心创作路径

核心路径

```text
文本(提示) + 图片(参考) → 视频(生成) → [音频] → 导出成片
```

典型最小闭环：

1. 添加 **图片**（上传角色/场景，或生成一张参考）
2. 添加 **文本**（写提示词；也可直接写在视频节点内）
3. 添加 **视频**，把图片（和可选文本）连上去
4. 点视频节点「生成」
5. 多个视频排进时间线 →「导出成片」

验收：空画布到首个成功视频预览 ≤ 3 分钟。

## 6. 边（连线）语义

边仍 **无类型选择器**。按下表自动解释：


| 源 → 目标            | 默认语义                           |
| ----------------- | ------------------------------ |
| 文本 → 图片 / 视频 / 音频 | 作为生成提示词或对白输入                   |
| 图片 → 图片           | 参考图 / 风格迁移输入                   |
| 图片 → 视频           | 画面参考（角色/场景/风格/关键帧由 role 或自动推断） |
| 视频 → 视频           | 时间线顺序 / 运动连续性参考                |
| 音频 → 视频           | 配乐或音效绑定到片段                     |
| 视频 → 音频           | 较少用；可表示「从画面生成音」的输入（后期）         |




### 6.1 禁止

- 无意义环（除产品明确允许的迭代环外，首期禁自环）
- 音频 → 文本 等无法解释的组合：不吸附 + 轻提示



### 6.2 生成时聚合

点击目标节点「生成」时，收集：

1. 节点自身字段（prompt / duration / aspectRatio …）
2. 所有入边源节点的媒体快照（文本正文、图片 URI、视频关键帧、音频 URI）
3. 画布 / 节点版本（对齐生成平台 subject）

**连上即使用**；不要求用户勾选「用哪些参考」。

## 7. 生成能力按媒体划分


| 节点  | 任务类型（生成平台）            | 首期           |
| --- | --------------------- | ------------ |
| 图片  | `IMAGE_GENERATION`    | 要            |
| 视频  | `VIDEO_GENERATION`    | 要            |
| 音频  | 预留 `AUDIO_GENERATION` | 可先只上传        |
| 文本  | 预留改写 / LLM            | 首期只编辑        |
| 成片  | `VIDEO_EXPORT`        | 要（画布级，非节点类型） |




## 8. 节点状态（四种共用）


| 状态  | 表现               |
| --- | ---------------- |
| 草稿  | 空内容或仅上传占位        |
| 生成中 | 进度；防重复提交         |
| 成功  | 预览可播放 / 可查看      |
| 失败  | 错误摘要 + 重试（新 Job） |


上传与生成是同一节点上的两种 **来源模式**，不是两种节点。

## 9. 时间线与导出

- 时间线主轨：**视频** 节点（成功产物）
- 可选附轨：**音频** 节点
- 默认顺序：视频→视频连线拓扑；无连线则按创建时间 / 手动拖拽
- 顶栏「导出成片」→ `VIDEO_EXPORT`；选项仅分辨率 + 格式

文本 / 图片不直接进成片时间线（图片可通过已生成的视频体现；字幕后期再挂文本轨）。

## 10. 界面信息架构

```text
┌──────────────────────────────────────────────────────────┐
│ Header：Luminova · 项目名 · 视图 Tab · 播放/导出           │
├────┬─────────────────────────────────────────────────────┤
│工具│                                                     │
│栏  │              无限画布                               │
│文本│   节点 = 顶栏工具 + 中心媒体 + 底栏模型操作（分离悬浮）│
│图片│   文本/图片 → 视频（±音频）                          │
│视频│   参数主入口在节点底部操作框，不依赖右侧大面板         │
│音频│                                                     │
├────┴─────────────────────────────────────────────────────┤
│ Timeline：视频轨（+ 音频轨） · 导出                        │
└──────────────────────────────────────────────────────────┘
```

工具栏 **只有 4 个添加入口**。若需「添加角色」，实现为：添加图片节点并预设 `role=character`（快捷菜单或模板），而不是第五个节点类型。

## 12. 功能需求（交互层）

- FR-UX-1：工具栏仅展示文本、图片、视频、音频
- FR-UX-2：业务概念（角色/场景/风格/镜头等）仅作为 `role` 扩展或快捷预设
- FR-UX-3：图片 / 视频节点支持上传与生成两种来源
- FR-UX-4：生成时自动聚合入边媒体快照
- FR-UX-5：边无类型选择器；非法组合不可连接
- FR-UX-6：节点采用三层结构——顶部悬空工具栏、中心媒体框、底部悬浮模型操作框
- FR-UX-7：常驻态仅渲染中心媒体框；点击选中后弹出顶栏与底栏；失焦后收回
- FR-UX-8：同一时刻通常只有当前选中节点展开顶栏与底栏
- FR-UX-9：模型参数与 prompt 默认放在底部操作框，不依赖右侧大面板作为主入口
- FR-UX-10：时间线以视频为主轨，导出为统一 Export Job
- FR-UX-11：节点状态与生成 Job 状态同步



## 13. 非目标

- 工具栏增加角色/场景/风格/镜头等独立类型
- 边类型编辑器、任意 DAG 编排器
- 默认暴露运镜、景别、光线、seed、参考强度
- 首期画布内精剪、复杂混音
- 把导出做成第五种节点类型（导出是画布级动作）



## 14. 成功指标

- 用户能用一句话概括节点体系：「就四种：文、图、视频、音频」
- 空画布 → 首个成功视频预览 ≤ 3 分钟
- 「节点类型太多 / 参数太多」类反馈下降

## 16. 开放问题

1. 「添加角色」快捷入口：放在工具栏长按图片，还是「模板」菜单？
2. 文本是否允许内嵌在图片/视频节点里（不强制独立文本节点）？建议：**允许**——独立文本节点用于复用同一段提示/对白连到多个目标。
3. 音频首期是否只上传、不生成？
4. 后端 `CanvasNodeType` 是否立即收敛为 4 枚举，还是先前端收敛、后端双写？
